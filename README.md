# O365Azure – Microsoft 365 / Power Platform / Azure / RPA Design & Learning Library

A personal portfolio of **design-process write-ups, learning notes, RPA bots, sample code and pre-sales material** covering SharePoint (2016 → Online), Power Automate (MS Flow), Power Apps, Dataverse, Microsoft Forms, MS Graph/Teams, UiPath RPA, Azure DevOps, Aspire/Dev Tunnels and Copilot Studio.

- **Total:** 37 items (zip contents analysed and summarised per zip; the `.ignore` folder is excluded).
- **Sorted:** latest → oldest by *effective date* (see note).
- Most `*.docx` files follow the **"AS A / I WANT / SO THAT → Solution → step-by-step screenshots"** pattern (the screenshot-heavy ones are large because of embedded images).

> **Effective date**: the date the content was authored/last saved, taken from the document's internal metadata (docx *modified*, PDF *creation*, newest file inside a zip). Where no internal date exists (marked `fs`) the file-system date (2026-10-26 / 2022-04-24) is used, which merely reflects when the repo was copied.
